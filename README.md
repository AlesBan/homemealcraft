# HomeMealCraft — Домашняя кухня

Telegram-бот для домашней кухни на двоих.  
**Фокус:** блюда и их состав → вручную понять, чего не хватает → список покупок.  
Ввод — JSON от ИИ-агента (голос/текст). Меню недели — позже.

## Модель

| Сущность | Роль |
|----------|------|
| **Блюдо** | Главное. «Паста карбонара» + список ингредиентов |
| **Ингредиент** | Абстрактный элемент состава («Паста», «Сливки») — без бренда |
| **Продукт** | Конкретный товар/перекус (~100–200 штук вручную). Штрихкод **не обязателен** |
| **Покупка** | То, что решили докупить после просмотра состава |

Сканер штрихкодов не в ежедневном потоке: максимум для перекусов с КБЖУ, если сами захотите.

Сценарий: «во вторник паста» → открыли блюдо → увидели ингредиенты → сами отметили, чего нет → добавили в покупки (пока вручную / через JSON).

БЖУ всегда на **100 г**, поля могут быть пустыми.
